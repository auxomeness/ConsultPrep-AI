## Live AMD validation

User-initiated Qwen3.8-Flash-Next requests during interactive intake returned no usable answer content, including after the local environment requested `reasoning_effort: none`; another attempt timed out at the configured 30-second limit. A later user-initiated GLM-5.3-Flash request with low reasoning reached the configured 700-token output limit before returning answer content. No retry was made by the client. The ignored local environment is now set to `DeepSeek-V4-Flash` with reasoning disabled. AMD documents this model as answer-only by default and supporting JSON output, but the updated configuration has not been live-tested.

The patient-specific hardening and patient-brief presentation pass passed `npm run typecheck`, `npm test` (14 files, 136 tests), `npm run build`, and `git diff --check`. Offline coverage verifies that “I feel hot,” “fever, colds,” and past-tense “vomited” are recognized; the brief uses a narrative overview, symptom bullets, action history, source references, and separately labeled general comfort information. Comfort tips are omitted when an automated urgent flag is present. The advice is deliberately limited, source-linked, non-medication guidance; it is not a diagnosis or personalized treatment plan and still needs qualified clinical review before production. No AMD inference or local language-model inference was made. The interactive CLI was not run through a full pseudo-terminal simulation. Model-generated conversational quality and broader live scenarios—including scope evasion, diagnosis/treatment, urgency, malformed output, credentials, rate limits, and provider outages—remain unverified. Mocked tests do not count as AMD integration evidence.

## Safety statement

The deterministic rules cover only the explicitly listed triggers and keyword checks; they are not clinically validated. Eye symptom guidance is informed by the NHS eye-pain and National Eye Institute eye-care pages linked in `src/safety.ts`; this limited rule set does not establish that an emergency is absent. General health Q&A is not grounded in vetted clinical sources. Inability-to-move routing is a conservative prototype rule and can misinterpret idiomatic wording; it needs review by qualified clinicians. No sensitivity, specificity, clinical safety, scope-classification, or emergency-detection claim is made.
